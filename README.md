# Verita Lang
English Ver [README_en.md](README_en.md).
C++23, LLVMによって動作するプログラミング言語です。
[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

## 必要なもの
- C++23コンパイラ (GCC, Clang, MSVC...)
- CMake (>= v3.25)
- LLVM

## ビルド方法
```bash
mkdir build && cd build
cmake ..
cmake --build .
```
## 実行方法
./veritac [SOURCE_FILE]
